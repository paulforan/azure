Receiver (wss server)Terminates guest chat sockets from web/mobile UI. Guest JWT (RX IdP) or anonymous session. Publishes inbound messages to Redis Streams. Owns reconnect + backpressure.
Redis StreamsConversation state and ordering. Consumer groups per Processor replica. Multi-AZ, persistence on.
ProcessorCalls Concierge Agent (HTTPS, API key/IAM). On TRANSFER_TO_AGENT: mints Genesys Messenger handoff (deploymentId Web|Mobile + customAttributes + summary) and tells UI to switch transport. Does not proxy the agent conversation (recommended pattern, see note).
Design decision required: who owns the socket after transfer?Option A (recommended): UI opens the Genesys Web Messaging guest session itself (token persisted for reconnect); gateway only passes deploymentId, session token and attributes. Reuses the Genesys Messenger SDK for typing, attachments, read receipts, history, and is exactly what the Digital Control Toggle does anyway. Option B (as drawn in v0.1): Processor opens the guest session and relays every agent message both ways for the rest of the chat: must re-implement reconnection, attachments, receipts, and doubles socket load. Either way the pre-transfer transcript reaches the agent only via VA_CONVERSATION_SUMMARY / CAD.

Use cases (Riyadh Air)
  • UC1Voice concierge. Guest calls; Genesys hands audio to WXO Voice Agent; ID&V; self-service or TRANSFER_TO_AGENT with tier/language → routed to BSG/Grey/Loyalty queue, preferred agent first.
  • UC2Social concierge. WhatsApp/Messenger/X message → Bot Connector → Social Agent; same handover contract; Grey queue on failure.
  • UC3Web & mobile concierge. Watson-first chat via RX gateway; on transfer the UI joins Genesys Web Messaging with the governed attributes so existing S1/S2/S3 flows and CRM preferred-agent routing run unchanged. Toggle reverts to legacy L1.
  • UC4Agent Assist (PROD today). Iframe + AudioHook Monitor (voice) or Notifications API (digital) + Knowledge search; summary at wrap-up.
  • UC5Callback. Concierge schedules a Genesys callback on the guest's behalf.
